
# ContainerOps

A containerized task-management application built to demonstrate practical DevOps engineering skills.

## Architecture

Browser → Nginx → Flask API → PostgreSQL + Redis

## Technology Stack

- Python and Flask
- Docker and Docker Compose
- PostgreSQL
- Redis
- Nginx
- Git and GitHub

## Project Goals

- Build and optimize Docker images.
- Containerize a Flask application.
- Manage services using Docker Compose.
- Configure container networking and persistent storage.
- Implement health checks and security best practices.
- Automate testing and builds using GitHub Actions.

## Current Status

Work in progress. Features and deployment instructions will be added as development continues.

## Learning Outcomes

Hands-on experience with containerization, image engineering, networking, deployment, automation, and troubleshooting.
